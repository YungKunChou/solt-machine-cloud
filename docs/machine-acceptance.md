# 第二版機台套用 — 人工確認項目

使用者已確認 `assets/design/slot-machine-compact-v2.png` 的視窗高度與整機比例。
正式遊戲頁使用此圖，`machine.css` 依 1448 × 1086 原圖座標裁切顯示機身及左右拉桿，不改動原圖、不重新生成素材。

## 本次變更

- 中央視窗對齊原圖內緣，保留暖色面板與金屬邊框；獎項／數量仍為 2：1。
- 選中列占滾輪顯示區約 60%，上下候選項淡化。播放器沿用量測後的列高與伺服器回合位置。
- 移除橫跨捲軸的固定水平線，改為左右短定位括框；括框向外移出半個線寬（約 1.5～2px），由視窗邊緣遮住靠外側的部分，呈現嵌入金屬框下的效果。保留金屬高光、暗邊和投影，捲軸文字在其後方移動。
- 已完成抽獎的玩家顯示「恭喜您抽中『獎項』× 數量！」，依玩家識別對應得獎紀錄，後續玩家抽獎時仍保留本人的結果。
- 所有狀態提示皆無外框、背景及標籤底色，以文字區分：等待／觀看／自動重新連線為灰褐色，輪到自己與抽獎完成為深金褐色，抽獎中為暖褐色，需要處理的錯誤為深紅色。保留文字標籤，輪到自己的提示及中獎獎項與數量加粗。
- 中獎揭曉時，中央視窗金屬框以獨立光暈層呈現整圈紅光，閃爍 3 次、共 2.4 秒；不受捲軸視窗裁切。系統設定「減少動態效果」時改為短暫靜態光暈。
- 連線提示優先於操作錯誤，一般排隊更新不會覆蓋錯誤；姓名及各滾輪的錯誤分別保留到對應操作成功或狀態已確認解決。提示帶預留高度，較長文字允許自然換行。
- 文字接近上下緣時逐漸壓縮高度、降低亮度，中央維持原比例；模糊量依即時速度與列高變化，減速時逐漸消退、停止時完全移除。特效只作用在內層文字，不改變回合時序與結果。
- 「本輪玩家：姓名／等待玩家加入」整合為機台上方同一行，長文字可自然換行；桌面機台區加寬，手機卡片左右內距縮小。
- 拉桿及下方按鈕共用開始／停止操作與等待鎖；主持人、非當前玩家及斷線時禁用。
- 圓球與金屬桿分層顯示：金屬桿隨行程縮短，圓球只平移、維持原始形狀和尺寸；兩者使用相同動畫時間與緩動，保持接合。
- 原機台 `slot-machine.png` 與設計第一版保留。

## 人工視覺確認（待使用者執行）

依 AGENTS.md 不進行瀏覽器截圖或自動視覺驗證；以下未宣稱已通過。

1. 桌面：確認金框內沒有文字越界、拉桿接點沒有明顯縫隙，玩家姓名與排隊資訊不互相遮擋。
2. 手機：以 320／390px 左右寬度檢查獎項換行、按鈕可點範圍，以及整頁是否出現水平捲動。
3. 抽獎：分別啟動兩支拉桿，再手動停止，檢查拉下、部分回彈及完全回位時，圓球持續保持圓形、尺寸不變且與金屬桿保持接合。
4. 長名稱：用較長的獎項檢查自動縮字後是否仍易讀。現有 120 字上限未更改；極長名稱仍會縮字，未保證所有名称都維持兩行或指定字級。
5. 投影：確認現有響應式版面的字級在實際投影距離可讀；本次未另增專用投影模式。
6. 擬真效果：確認上下曲面過渡自然、高速模糊輕微，兩輪各自減速後恢復清晰，中央結果不壓縮；系統設定「減少動態效果」時關閉文字曲面與模糊。
7. 提示帶：手機與投影分別確認各狀態皆無外框、背景及標籤底色，灰褐、深金褐及深紅色文字清楚可讀；輪到自己時文字加粗，中獎結果持續顯示本人的獎項與數量。
8. 提示切換：確認短訊息之間切換時版面穩定，長姓名、長獎項與錯誤訊息可完整換行；自動重新連線顯示中性色，恢復連線後回到正確的遊戲提示。
9. 簡約結果與揭曉：確認抽獎完成提示沒有外框或底色，本輪玩家標籤與姓名同一行；完成兩輪抽獎時視窗框整圈紅光閃爍 3 次，獎項文字持續清楚可讀。
