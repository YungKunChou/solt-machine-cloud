# 歷史封存

此處集中保存已停用的檔案。封存是搬移保留，沒有刪除原始內容；正式程式與本機資源清單不載入此資料夾。

## 2026-09-27 整理

| 資料夾 | 內容 | 保存方式 |
| --- | --- | --- |
| [design](2026-09-27/design/) | 舊機台圖、v1／v2 設計、拉桿姿態提案及提示詞；預覽頁與圖片維持同一資料夾 | 原本受 Git 管理的素材，仍可納入版本管理 |
| [docs](2026-09-27/docs/) | 初版設定介面的歷史驗證紀錄 | 可納入版本管理 |
| [misc](2026-09-27/misc/) | 根目錄原有的空白檔案 `{` | 可納入版本管理 |
| `2026-09-27/local-only/legacy/` | 舊後端、舊說明書、流程圖與 PDF | 僅保存在本機，排除於 Git |
| `2026-09-27/local-only/setup/` | 原始備份、上游快照、房間資料備份、舊設計稿、截圖、影片拆幀與舊日誌 | 僅保存在本機，排除於 Git |

`local-only/` 延續搬移前的忽略設定，避免將舊後端或房間資料備份加入儲存庫；換電腦時需另外複製保存。原始備份與上游快照保留完整目錄結構，可能包含重複檔案。

目前使用的機台及球頭圖片仍在根目錄下的 `assets/design/`；目前後端為根目錄 `index.js` 與相關模組。`docs/` 的機台與滾輪驗收文件仍保留供維護使用。

`.local-setup/npm-cache/` 與根目錄 `local-preview*.log` 留在原處，屬快取／執行日誌。根目錄的 `node_modules/` 是目前開發依賴，未搬移。

封存文件中的舊版本資訊屬歷史紀錄，不代表現行功能或目前驗收結果。查找搬移對應請見 [搬移清單](2026-09-27/搬移清單.csv)。
